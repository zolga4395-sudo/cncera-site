## 🏗 Архитектура Решения

### Workflow A: Competitor Price Scraper - MAIN

```
Cron (10:00) → Telegram Start → Notion Query → HTTP Fetch 
→ Extract Data → Calculate Diff → IF Parser Success?
   ├─ Yes → Call RAG API → IF Has Changes?
   │           ├─ Yes → Telegram Report
   │           └─ No → (skip notification)
   └─ No → Telegram Error
                 ↓
         Update Notion
```

**Функции:**
- ⏰ Автоматический запуск по расписанию
- 📋 Получение списка конкурентов из Notion
- 🌐 Парсинг веб-страниц (HTTP + cheerio)
- 🧮 Расчет изменения цен
- 🤖 Вызов AI анализа через Webhook
- 📱 Уведомления в Telegram
- ✏️ Обновление Notion

### Workflow B: Competitor Price Scraper - RAG API

```
Webhook → Merge → Prepare Content
   ├─→ Supabase Insert (векторы)
   └─→ RAG Agent
        ├─ Vector Store (контекст)
        ├─ Memory (история)
        └─ Claude AI (анализ)
             ↓
        Response → Webhook Response
```

**Функции:**
- 🎯 REST API endpoint (Webhook)
- 🔢 Векторизация данных (OpenAI Embeddings)
- 💾 Хранение в Supabase Vector Store
- 🔍 Поиск релевантного контекста
- 🤖 AI анализ с Claude (Anthropic)
- 🧠 Сохранение памяти разговора
- ↩️ Возврат структурированного ответа

## 🚀 Что Нужно для Запуска

### Требования

#### Обязательные Сервисы
1. **n8n instance** (cloud или self-hosted)
2. **Notion workspace** (бесплатный план ОК)
3. **Supabase project** (бесплатный план ОК)
4. **Anthropic API key** (платно, ~$0.003/1K токенов)
5. **OpenAI API key** (платно, ~$0.0001/1K токенов)
6. **Telegram bot** (бесплатно)

#### Расчетная Стоимость
- **10 конкурентов × 1 проверка/день:**
  - OpenAI (embeddings): ~$0.05/месяц
  - Anthropic (анализ): ~$0.10/месяц
  - **Итого: ~$0.15/месяц**

- **50 конкурентов × 1 проверка/день:**
  - **Итого: ~$0.50/месяц**

- **100 конкурентов × 2 проверки/день:**
  - **Итого: ~$2.00/месяц**

### Время Настройки
- **Первая настройка:** 60-75 минут (следуя SETUP-GUIDE.md)
- **Повторная настройка:** 15-20 минут (если уже знаком)
- **Добавление конкурента:** 2-3 минуты
