## 📋 Использование

### 1. Загрузка и анализ
1. Выберите файл STEP/STL
2. Настройте параметры анализа
3. **Выберите начало координат (G54-G59)**
4. Нажмите "Анализировать"

### 2. Автоматический анализ с ИИ
- После анализа автоматически запускается чат с ИИ
- ИИ получает данные анализа и дает рекомендации
- Можно задавать дополнительные вопросы

### 3. CAM рекомендации
- Нажмите "Получить CAM рекомендации"
- Выберите провайдера ИИ
- Получите структурированные рекомендации

### 4. Генерация G-кода
- Настройте параметры обработки
- Выберите контроллер
- Нажмите "Сгенерировать G-код"
- Скачайте готовый G-код
