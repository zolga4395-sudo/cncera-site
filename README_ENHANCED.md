# CNCera Enhanced - Расширенная версия с ИИ

## Описание
Полностью функциональное Flask-приложение для детального анализа 3D-моделей через FreeCAD и генерации CAM рекомендаций с помощью ИИ.

## Новые возможности

### 🔍 Детальный анализ геометрии
- **Офлайн-анализ** через FreeCAD для STEP/STL файлов
- **Распознавание элементов**: отверстия, карманы, фаски, резьбы, выступы, бобышки
- **Извлечение размеров** и определение материала детали
- **Структурированный JSON-вывод** с полной информацией о геометрии

### 🤖 ИИ-интеграция для CAM
- **Поддержка провайдеров**: OpenAI (GPT), Anthropic (Claude), xAI (Grok)
- **Подбор инструментов** и патронов (BT, HSK и др.)
- **Расчет режимов резания** (Vc, n, fz, F, ap, ae) по материалу
- **План операций** (черновая → получистовая → чистовая)
- **Генерация G-кода** для различных контроллеров

### 📊 Структурированный вывод
1. **Список распознанных элементов** детали
2. **Рекомендованные инструменты** и патроны
3. **Таблица режимов резания**
4. **Последовательность операций**
5. **Полный G-код** для выбранного контроллера

## Установка

### Зависимости
```bash
pip3 install Flask requests --break-system-packages
```

### Переменные окружения
```bash
# Пути к FreeCAD (обязательно)
FREECAD_PATH=C:\Program Files\FreeCAD_1.0.1-conda-Windows-x86_64-py311\bin
FREECAD_CMD=C:\\Program Files\\FreeCAD_1.0.1-conda-Windows-x86_64-py311\\bin\\FreeCADCmd.exe

# API ключи для ИИ (опционально)
OPENAI_API_KEY=your_openai_key
ANTHROPIC_API_KEY=your_anthropic_key
XAI_API_KEY=your_xai_key
```

## Запуск
```bash
python3 app.py
```

Приложение будет доступно по адресу: **http://localhost:5000**

## Использование

### 1. Загрузка и анализ файла
- Загрузите STEP или STL файл
- Настройте параметры анализа (единицы, отклонения)
- Нажмите "Анализировать"

### 2. Просмотр результатов
- **3D-просмотр** модели (Three.js или PNG)
- **Детальный анализ геометрии** с распознанными элементами
- **Размеры и характеристики** детали

### 3. Получение CAM рекомендаций
- Выберите ИИ провайдера (OpenAI/Claude/Grok)
- Нажмите "Получить CAM рекомендации"
- Просмотрите структурированные рекомендации:
  - Инструменты и патроны
  - Режимы резания
  - План операций
  - G-код для контроллеров

### 4. Генерация G-кода
- Настройте параметры обработки
- Выберите контроллер и тип операции
- Сгенерируйте и скачайте G-код

## Поддерживаемые контроллеры
- **Fanuc** - стандартные G-коды
- **Siemens** - с поддержкой G71
- **Heidenhain** - с BLK FORM
- **GSK** - китайские контроллеры
- **Mazak** - с M99
- **Haas, Okuma, Mitsubishi** - через ИИ рекомендации

## Типы операций
- **Фрезерная обработка** - с адаптивными стратегиями
- **Токарная обработка** - черновая/чистовая/подрезка
- **Сверление** - с циклами G81/G82/G83
- **Фаски** - по периметру детали
- **Черновая/чистовая** - с разными параметрами

## Особенности реализации

### Офлайн-анализ
- Использует FreeCAD для точного анализа геометрии
- Распознает цилиндрические отверстия, прямоугольные карманы
- Определяет наклонные поверхности (фаски)
- Анализирует сложность и предполагает материал

### ИИ-интеграция
- Структурированные промпты для получения JSON-ответов
- Fallback на базовые рекомендации без ИИ
- Поддержка множественных провайдеров
- Валидация и обработка ответов ИИ

### Безопасность
- Валидация имен файлов
- Ограничения размера файлов
- Санитизация параметров G-кода
- Обработка ошибок и исключений
