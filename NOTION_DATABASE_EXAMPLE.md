# 📊 Пример структуры базы данных Notion для агента

## Создание базы данных

1. Откройте Notion
2. Создайте новую страницу
3. Добавьте Database → Table (Таблица)
4. Назовите её, например: "Мониторинг конкурентов - Туры"

---

## 🗂️ Структура полей (Properties)

### Обязательные поля:

| № | Название поля | Тип поля | Описание | Пример значения |
|---|--------------|----------|----------|-----------------|
| 1 | **Name** или **Название** | Title | Название тура конкурента | "Вулканы Камчатки - 7 дней" |
| 2 | **URL конкурента** или **URL** | URL | Ссылка на страницу тура | https://competitor.ru/tour/vulkany |
| 3 | **Последняя цена** | Number | Последняя зафиксированная цена | 85000 |
| 4 | **Последний статус** | Text | Последнее зафиксированное описание | "Тур включает посещение..." |
| 5 | **Дата проверки** | Date | Дата последней проверки | 07.10.2025 |
| 6 | **Статус парсинга** | Text | Статус последней проверки | "OK" или "Ошибка" |

### Опциональные поля (можно добавить):

| № | Название поля | Тип поля | Описание | Пример значения |
|---|--------------|----------|----------|-----------------|
| 7 | **Конкурент** | Select | Название компании-конкурента | "Камчатка-Тревел", "Вулкан-Тур" |
| 8 | **Категория тура** | Select | Тип тура | "Вулканы", "Рыбалка", "Сплав" |
| 9 | **Длительность** | Number | Количество дней | 7 |
| 10 | **Приоритет** | Select | Важность мониторинга | "Высокий", "Средний", "Низкий" |
| 11 | **Заметки** | Text | Дополнительные заметки | "Основной конкурент" |

## 🔧 Настройка в Notion

### Шаг 1: Создайте поля

1. Откройте вашу таблицу в Notion
2. Нажмите на "+" справа от последнего столбца
3. Выберите тип поля (Title, URL, Number, Text, Date)
4. Введите название поля **ТОЧНО** как указано выше

**⚠️ ВАЖНО:** Названия полей должны совпадать с теми, что используются в коде агента!

### Шаг 2: Настройте типы полей

#### URL конкурента / URL:
- Тип: **URL**
- Это специальный тип поля для ссылок

#### Последняя цена:
- Тип: **Number**
- Number format: Number (без знака валюты)

#### Последний статус:
- Тип: **Text**
- Можно использовать "Rich text"

#### Дата проверки:
- Тип: **Date**
- Format: любой удобный

#### Статус парсинга:
- Тип: **Text** или **Select**
- Если Select, создайте опции: "OK", "Ошибка"

## 🔑 Получение Database ID

1. Откройте вашу базу данных в Notion в браузере
2. Скопируйте URL страницы
3. URL выглядит так:
   ```
   https://www.notion.so/workspace/1234567890abcdef1234567890abcdef?v=...
                                  ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
                                  Это ваш DATABASE_ID
   ```
4. Скопируйте 32-символьный ID (без дефисов)
5. Вставьте в переменную окружения `NOTION_DATABASE_ID` в n8n

**Пример:**
```
URL: https://www.notion.so/myworkspace/1234567890abcdef1234567890abcdef?v=xxx
DATABASE_ID: 1234567890abcdef1234567890abcdef
```

## 🔐 Настройка доступа для API

1. Откройте Settings & Members в Notion
2. Перейдите в "Connections" (или "Integrations")
3. Найдите вашу интеграцию (или создайте новую)
4. Откройте страницу с базой данных
5. Нажмите "..." (три точки) → "Connect to"
6. Выберите вашу интеграцию
7. Теперь API имеет доступ к базе данных

## 🎯 Советы

1. **Группировка по конкурентам**: Добавьте поле "Конкурент" (Select) и группируйте записи
2. **Фильтры**: Создайте фильтры для отображения только активных туров
3. **Сортировка**: Сортируйте по дате проверки, чтобы видеть последние обновления
4. **Представления (Views)**: Создайте разные представления:
   - "Все туры"
   - "Только ошибки парсинга"
   - "Изменения за последнюю неделю"
   - "По конкурентам"

---

## 🔄 Как будет работать обновление

После запуска агента:

1. **Первый запуск:**
   - Агент загрузит HTML страницы
   - Извлечет текущую цену и описание
   - Сохранит в "Последняя цена" и "Последний статус"
   - Обновит "Дату проверки"
   - Установит "Статус парсинга" = "OK" или "Ошибка"

2. **Последующие запуски:**
   - Агент сравнит новую цену со старой
   - Если есть изменения → отправит уведомление в Telegram
   - Обновит все поля в Notion
