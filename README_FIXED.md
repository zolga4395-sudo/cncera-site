# CNCera Enhanced - Fixed Version

## Исправленные проблемы

### ✅ 1. Проблема с обнаружением модели при генерации G-code
- **Проблема**: При генерации G-code система не видела загруженную модель
- **Решение**: Добавлена валидация существования файла модели перед генерацией G-code
- **Код**: В функции `generate_gcode_enhanced()` добавлена проверка `model_file.exists()`

### ✅ 2. Ошибка 404 при получении рекомендаций от ИИ
- **Проблема**: При нажатии на кнопку "дать рекомендации" возникала ошибка 404
- **Решение**: Исправлены маршруты API и добавлена правильная обработка ошибок
- **Код**: Улучшена функция `ai_chat_enhanced()` с корректной обработкой ошибок API

### ✅ 3. Проблема с переменной окружения XAI_API_KEY
- **Проблема**: Grok выдавал ошибку о не настроенном API ключе
- **Решение**: Добавлена проверка и правильная обработка API ключей для всех провайдеров
- **Код**: В `EnhancedAIService` добавлена функция `get_api_key()` с детальными сообщениями об ошибках

### ✅ 4. Анализ количества установок для обработки модели
- **Проблема**: После анализа модели не указывалось количество установок
- **Решение**: Добавлен класс `ModelAnalyzer` с анализом сложности и расчетом установок
- **Код**: Функция `analyze_model_complexity()` рассчитывает количество установок на основе геометрии

### ✅ 5. RAG база для ИИ с знаниями о G-code
- **Проблема**: ИИ не имел специализированных знаний о G-code и обработке
- **Решение**: Создана SQLite база данных с знаниями о G-code, материалах и инструментах
- **Код**: Класс `RAGDatabase` с таблицами `gcode_knowledge`, `material_properties`, `tooling_knowledge`

### ✅ 6. NC Viewer для проверки G-code
- **Проблема**: Не было возможности визуализировать сгенерированный G-code
- **Решение**: Добавлен класс `NCViewer` с парсингом G-code и SVG визуализацией
- **Код**: Функции `parse_gcode()` и `displayNCViewer()` для анализа и отображения траекторий

### ✅ 7. Улучшенная обработка ошибок и взаимосвязи
- **Проблема**: Недостаточная обработка ошибок и плохие взаимосвязи между компонентами
- **Решение**: Добавлены классы `ErrorHandler` и `CNCeraError` с детальной классификацией ошибок
- **Код**: Улучшена обработка исключений во всех маршрутах Flask

## Новые возможности

### 🆕 RAG Database (Retrieval-Augmented Generation)
- База знаний о G-code командах и их использовании
- Свойства материалов и рекомендации по обработке
- База инструментов с параметрами резания
- Автоматическое обогащение контекста для ИИ

### 🆕 Model Complexity Analyzer
- Анализ сложности 3D модели
- Расчет количества установок для обработки
- Оценка времени обработки
- Рекомендации по стратегии обработки

### 🆕 Enhanced AI Service
- Интеграция с RAG базой знаний
- Улучшенные промпты с контекстом
- Поддержка OpenAI, Anthropic, xAI
- Детальная обработка ошибок API

### 🆕 NC Viewer
- Парсинг G-code файлов
- Визуализация траекторий инструмента
- Статистика программы
- Анализ времени обработки

## Установка и настройка

### 1. Установка зависимостей
```bash
pip install flask requests matplotlib numpy-stl sqlite3
```

### 2. Настройка API ключей
```bash
# OpenAI
export OPENAI_API_KEY="your-openai-api-key"

# Anthropic
export ANTHROPIC_API_KEY="your-anthropic-api-key"

# xAI (Grok)
export XAI_API_KEY="your-xai-api-key"
```

### 3. Запуск приложения
```bash
python cncera_enhanced_final.py
```

### 4. Доступ к приложению
Откройте браузер и перейдите по адресу: `http://localhost:5000`

## Использование

### 1. Загрузка и анализ модели
- Загрузите файл .step, .stp или .stl
- Настройте параметры анализа
- Нажмите "Анализировать"
- Просмотрите результаты анализа сложности

### 2. Чат с ИИ
- Выберите провайдера ИИ
- Задайте вопросы о детали
- Получите рекомендации с учетом RAG базы знаний

### 3. Генерация G-code
- Настройте параметры обработки
- Выберите контроллер и тип операции
- Нажмите "Сгенерировать G-код"
- Просмотрите результат в NC Viewer

### 4. NC Viewer
- Автоматически отображается после генерации G-code
- Показывает траектории инструмента
- Отображает статистику программы
- Анализирует время обработки

## API Endpoints

### Основные маршруты
- `POST /upload` - Загрузка и анализ файла
- `POST /generate_gcode` - Генерация G-code
- `POST /ai_chat` - Чат с ИИ
- `POST /analyze_complexity` - Анализ сложности модели
- `POST /parse_gcode` - Парсинг G-code для NC Viewer
- `POST /cam_analysis` - CAM анализ с ИИ

### Вспомогательные маршруты
- `GET /metrics` - Метрики системы
- `GET /health` - Проверка здоровья системы
- `GET /models/<filename>` - Скачивание файлов

## Устранение неполадок

### Проблема: "API ключ не настроен"
**Решение**: Установите переменные окружения для нужных провайдеров ИИ

### Проблема: "Model file not found"
**Решение**: Убедитесь, что файл модели был успешно загружен перед генерацией G-code

### Проблема: "FreeCAD not found"
**Решение**: Установите FreeCAD и добавьте путь к FreeCADCmd в PATH

### Проблема: "Database locked"
**Решение**: Убедитесь, что база данных не используется другим процессом
