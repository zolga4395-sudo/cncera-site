# CNCera Enhanced - Готовый к запуску

## Описание
Полностью рабочий Flask-приложение для анализа 3D-геометрии и генерации G-кода для различных ЧПУ контроллеров.

## Особенности
- ✅ Все классы встроены в app.py
- ✅ Правильные пути к FreeCAD из переменных окружения
- ✅ Минимальные зависимости (только Flask и requests)
- ✅ Упрощенный анализ STL без numpy/matplotlib
- ✅ Полная функциональность генерации G-кода
- ✅ AI чат с поддержкой OpenAI, Anthropic, xAI
- ✅ Мониторинг системы и метрики
- ✅ Безопасность и валидация входных данных

## Установка зависимостей
```bash
pip3 install Flask requests --break-system-packages
```

## Переменные окружения
```bash
# Пути к FreeCAD (уже настроены в коде)
FREECAD_PATH=C:\Program Files\FreeCAD_1.0.1-conda-Windows-x86_64-py311\bin
FREECAD_CMD=C:\\Program Files\\FreeCAD_1.0.1-conda-Windows-x86_64-py311\\bin\\FreeCADCmd.exe

# API ключи для AI чата (опционально)
OPENAI_API_KEY=your_openai_key
ANTHROPIC_API_KEY=your_anthropic_key
XAI_API_KEY=your_xai_key
```

## Запуск
```bash
python3 app.py
```

Приложение будет доступно по адресу: http://localhost:5000

## Функциональность
1. **Загрузка файлов**: STL, STEP, STP
2. **Анализ геометрии**: размеры, объем, площадь поверхности
3. **Генерация G-кода**: для Fanuc, Siemens, Heidenhain, GSK, Mazak
4. **Типы операций**: фрезерование, токарная обработка, сверление, фаски
5. **AI чат**: консультации по ЧПУ обработке
6. **Мониторинг**: метрики системы и производительности
