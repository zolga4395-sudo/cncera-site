# CNCera Enhanced - Полная версия с ИИ и 3D визуализацией

## 🚀 Описание
Полностью функциональное Flask-приложение для детального анализа 3D-моделей через FreeCAD с интеграцией ИИ для CAM-рекомендаций и генерации G-кода.

## ✨ Ключевые возможности

### 🔍 Детальный офлайн-анализ геометрии
- **FreeCAD-интеграция** для точного анализа STEP/STL файлов
- **Распознавание элементов**:
  - Отверстия (цилиндрические, сквозные, глухие)
  - Карманы (прямоугольные, ступенчатые)
  - Фаски (наклонные поверхности, скосы)
  - Резьбы (внешние, внутренние)
  - Бобышки и выступы
  - Протрузии
- **Анализ размеров** и определение материала детали
- **Допуски** и точность обработки
- **Структурированный JSON-вывод** с полной информацией

### 🎮 3D визуализация
- **Three.js** с OrbitControls для интерактивного просмотра
- **STLLoader** для загрузки 3D моделей
- **Отображение 0 точки** над поверхностью детали
- **Координатные оси** для ориентации
- **PNG fallback** если Three.js недоступен
- **Адаптивное освещение** и тени

### 🤖 ИИ-интеграция
- **Поддержка провайдеров**:
  - OpenAI (GPT-4)
  - Anthropic (Claude-3-Sonnet)
  - xAI (Grok)
- **Чат с ИИ** для анализа детали
- **CAM рекомендации** с подбором инструментов
- **API ключи** из переменных окружения

### 📊 Структурированные CAM рекомендации
1. **Список распознанных элементов** детали
2. **Рекомендованные инструменты** и патроны (BT, HSK и др.)
3. **Таблица режимов резания** (Vc, n, fz, F, ap, ae)
4. **Последовательность операций** (черновая → получистовая → чистовая)
5. **Полный G-код** для различных контроллеров

### 🎯 Поддерживаемые контроллеры
- **Fanuc** - стандартные G-коды
- **Siemens** - с поддержкой G71
- **Heidenhain** - с BLK FORM
- **GSK** - китайские контроллеры
- **Mazak** - с M99
- **Haas, Okuma, Mitsubishi** - через ИИ рекомендации

## 🛠 Установка

### Зависимости
```bash
pip3 install Flask requests --break-system-packages
```

### Переменные окружения
```bash
# Пути к FreeCAD (обязательно)
FREECAD_PATH=C:\Program Files\FreeCAD_1.0.1-conda-Windows-x86_64-py311\bin
FREECAD_CMD=C:\\Program Files\\FreeCAD_1.0.1-conda-Windows-x86_64-py311\\bin\\FreeCADCmd.exe

# API ключи для ИИ (опционально)
OPENAI_API_KEY=your_openai_key
ANTHROPIC_API_KEY=your_anthropic_key
XAI_API_KEY=your_xai_key
```

## 🚀 Запуск
```bash
python3 app.py
```

Приложение будет доступно по адресу: **http://localhost:5000**

## 📋 Использование

### 1. Загрузка и анализ файла
- Загрузите STEP или STL файл
- Настройте параметры анализа (единицы, отклонения)
- Нажмите "Анализировать"

### 2. 3D просмотр
- **Интерактивная 3D модель** с возможностью вращения
- **0 точка** отображается красной сферой над деталью
- **Координатные оси** для ориентации
- **Адаптивное масштабирование**

### 3. Детальный анализ геометрии
- **Распознанные элементы** с размерами и характеристиками
- **Материал детали** определенный по геометрии
- **Допуски** для отверстий и поверхностей
- **Сложность** и точность обработки

### 4. Чат с ИИ
- Выберите провайдера ИИ
- Задавайте вопросы о детали
- Получайте рекомендации по обработке
- Анализируйте инструменты и режимы резания

### 5. CAM рекомендации
- **Автоматический подбор инструментов** и патронов
- **Расчет режимов резания** по материалу
- **План операций** с последовательностью
- **G-код** для выбранного контроллера

### 6. Генерация G-кода
- Настройте параметры обработки
- Выберите контроллер и тип операции
- Сгенерируйте и скачайте G-код

## 🏗 Архитектура

### Backend (Python/Flask)
- **FreeCAD интеграция** для анализа геометрии
- **ИИ API** для рекомендаций
- **G-code генератор** для различных контроллеров
- **Обработка ошибок** и валидация

### Frontend (HTML/JavaScript)
- **Three.js** для 3D визуализации
- **Tailwind CSS** для стилизации
- **Адаптивный дизайн** для всех устройств
- **Интерактивные элементы** управления

## 🔧 Технические особенности

### Офлайн-анализ
- Использует FreeCAD для точного анализа геометрии
- Распознает цилиндрические отверстия, прямоугольные карманы

- Анализирует сложность и предполагает материал

- Three.js с WebGL рендерингом

- Структурированные промпты для получения JSON-ответов
- Fallback на базовые рекомендации без ИИ
- Поддержка множественных провайдеров
- Валидация и обработка ответов ИИ
- Контекстный анализ с данными геометрии

### Безопасность
- Валидация имен файлов
- Ограничения размера файлов
- Санитизация параметров G-кода
- Обработка ошибок и исключений
- Логирование всех операций
