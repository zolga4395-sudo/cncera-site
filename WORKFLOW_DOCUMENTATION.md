# Combined RSS & Visa Monitor Workflow - Документация

## Обзор

Этот n8n workflow объединяет две независимые функции:
1. **RSS Мониторинг** - автоматический парсинг новостей из RSS-лент с извлечением контактов и публикацией в Telegram
2. **Visa Мониторинг** - обработка запросов через Telegram-бота для поиска информации о посольствах и визовых центрах

---

## 🔄 Часть 1: RSS Workflow

### Основной поток:

```
Запуск по расписанию (каждые 3 часа)
  ↓
RSS Read (TechCrunch AI Feed)
  ↓
Loop Over Items (по одному)
  ↓
Wait (5 секунд между элементами)
  ↓
Supabase: Проверка обработанных URL
  ↓
IF: URL не обработан? (проверка длины массива = 0)
  ├─ ДА → Продолжить обработку
  └─ НЕТ → Вернуться к Loop (пропустить)
```

### Обработка новой статьи:

```
Установка переменных (url_site, article_title, api_key_firecrawl)
  ↓
Firecrawl: Парсинг страницы (markdown + screenshot)
  ↓
  ├─→ Извлечение контактов (emails, phones, social media)
  │     ↓
  │   Создать пост (форматирование HTML)
  │     ↓
  │   Объединение данных ←────┐
  │                           │
  └─→ Получить скриншот ──────┘
        ↓
      Отправить в Telegram (RSS)
        ↓
      Supabase: Сохранить обработанный
        ↓
      Continue Loop → возврат к "Loop Over Items"
```

### Ключевые особенности:

- **Дедупликация**: Проверка URL в Supabase перед обработкой
- **Извлечение контактов**: Regex для email, телефонов, Telegram, WhatsApp, Instagram, Facebook, LinkedIn
- **Форматирование**: HTML-форматированный пост с эмодзи
- **Скриншот**: Визуальное представление статьи
- **Задержка**: 5 секунд между элементами для предотвращения rate limiting

## 📱 Часть 2: Visa Workflow

### Основной поток:

```
Webhook /telegram (POST)
  ↓
Определить команду /visa (парсинг текста)
  ↓
IF: не /visa? (проверка skip=true)
  ├─ ДА → Стоп: не /visa
  └─ НЕТ → Продолжить
       ↓
     IF: есть query? (проверка параметров)
       ├─ НЕТ → Подсказка формата
       └─ ДА → Сформировать поисковый запрос
```

### Обработка визового запроса:

```
Сформировать поисковый запрос
  ("посольство OR визовый центр {query} site:uz")
  ↓
Firecrawl: Поиск посольств (limit: 5)
  ↓
Выбрать лучший URL (ранжирование по relevance)
  ↓
IF: найден URL?
  ├─ НЕТ → Отправить: не найдено
  └─ ДА → Firecrawl: Страница посольства
           ↓
         Проверка наличия слотов
           (анализ markdown на ключевые слова)
           ↓
         Форматировать сообщение о визе
           (статус слотов + контакты)
           ↓
         Отправить результат о визе
           ↓
         Supabase: Сохранить запрос визы
```

### Логика ранжирования URL:

URL оценивается по системе баллов:
- `.uz` домен: +3
- `vfsglobal`: +3
- `visametric`: +3
- `embassy` или `mfa`: +2
- `consulate`: +2

Выбирается URL с наивысшим баллом.

### Проверка слотов:

Поиск в markdown следующих ключевых слов:
- `appointment`, `book`, `signup`, `enroll`
- `next date`, `available`, `open slot`
- `запись`, `доступн`, `свободн`

### Формат ответа:

```
🏛 Информация о визе: {query}

✅ Возможна запись! / ⚠️ Статус неясен

🔗 Сайт: {url}

📧 Email:
  • email1@example.com
  • email2@example.com

☎️ Телефоны:
  • +998 XX XXX XX XX
  • +998 YY YYY YY YY

💡 Рекомендуем связаться с посольством для уточнения деталей
```

## 🔍 Особенности реализации

### 1. Обработка ошибок:
- `alwaysOutputData: true` на проверке Supabase
- `onError: continueRegularOutput` для продолжения при ошибках

### 2. Оптимизация:
- Batch processing по 1 элементу для контроля
- Wait между запросами для rate limiting
- Проверка дублей в Supabase

### 3. Извлечение данных:
- Regex для контактов
- Анализ markdown на ключевые слова
- Ранжирование результатов поиска

### 4. Форматирование:
- HTML для Telegram
- Эмодзи для визуализации
- Ограничение длины сообщений (1000 символов для RSS)

## 📊 Метрики и мониторинг

Workflow сохраняет в Supabase:
- Все обработанные URL из RSS
- Все запросы на визовую информацию
- Timestamp каждой операции
- Статус наличия слотов

Это позволяет:
- Отслеживать популярные запросы
- Анализировать доступность слотов
- Избегать повторной обработки

## 🛠️ Требования

### Supabase таблицы:

**processed_urls:**
```sql
CREATE TABLE processed_urls (
  id SERIAL PRIMARY KEY,
  url TEXT UNIQUE NOT NULL,
  processed_at TIMESTAMP WITH TIME ZONE,
  post_text TEXT
);
```

**visa_queries:**
```sql
CREATE TABLE visa_queries (
  id SERIAL PRIMARY KEY,
  chat_id TEXT NOT NULL,
  query TEXT NOT NULL,
  found_url TEXT,
  has_slots BOOLEAN,
  queried_at TIMESTAMP WITH TIME ZONE
);
```

### Telegram Webhook:

Настройте webhook для Telegram бота:
```
https://your-n8n-instance.com/webhook/telegram
```

## 📝 Примечания

1. **API лимиты**: Firecrawl может иметь ограничения по количеству запросов
2. **Точность**: Проверка слотов работает на основе ключевых слов и может давать ложные срабатывания
3. **Обновления**: RSS проверяется каждые 3 часа, можно изменить в триггере
4. **Локализация**: Поддержка русского языка в сообщениях и поиске
