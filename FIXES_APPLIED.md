# Исправления критических ошибок в app.py

## ✅ Исправленные проблемы

### 1. Дублирование маршрутов Flask
- **Проблема**: Один и тот же путь объявлялся несколько раз, что вызывало `AssertionError: View function mapping is overwriting an existing endpoint`
- **Исправление**: Удалены все дубликаты, оставлен только один экземпляр каждого маршрута

### 2. Обрыв кода
- **Проблема**: Незавершенная строка `meta = generate_drilling` в конце файла
- **Исправление**: Удален обрыв кода

### 3. Несогласованность параметров G-code
- **Проблема**: В генерации G-code использовался параметр `tool` вместо `tool_diam`
- **Исправление**: 
  - В функции `generate_enhanced_milling_gcode`: `validated_params.get("tool_diam", 3.0)`
  - В JavaScript фронтенда: `tool_diam: parseFloat(document.getElementById('tool').value || '3')`

### 4. Конфликт версий /gcode_preview
- **Проблема**: Две несовместимые реализации - JSON API и HTML версия
- **Исправление**: Оставлена только JSON версия с параметром `name`, возвращающая первые 40 строк

### 5. Несогласованность /download_gcode
- **Проблема**: Разные сигнатуры параметров (`name` vs `filename`)
- **Исправление**: Унифицирован интерфейс с параметром `filename`

### 6. Дублирование /chat
- **Проблема**: Две версии обработчика с разной логикой
- **Исправление**: Оставлена одна версия с полной валидацией и обработкой ошибок
