## 📄 Описание Файлов

### 1. workflow-a-competitor-price-scraper-main.json

**Назначение:** Основной n8n воркфлоу для мониторинга цен

**Содержит:**
- Cron триггер (ежедневно в 10:00)
- Интеграцию с Notion (получение списка конкурентов)
- HTTP парсинг веб-страниц
- JavaScript код для извлечения данных (cheerio)
- Расчет разницы цен
- Условную логику (ветвление)
- Вызов RAG API через Webhook
- Telegram уведомления (старт, ошибки, отчеты)
- Обновление Notion

**Ноды:** 14
- 1× Cron Trigger
- 3× Telegram
- 2× Notion
- 1× HTTP Request
- 2× Code
- 2× IF
- 1× HTTP Request (Webhook call)
- 1× Sticky Note

**Импорт:**
```bash
n8n import workflow workflow-a-competitor-price-scraper-main.json
```

## 🛠 Кастомизация

### Какой файл менять для:

**Изменить расписание запуска:**
- Файл: `workflow-a-competitor-price-scraper-main.json`
- Нода: `Cron Trigger (Daily 10:00)`
- Параметр: `cronExpression`

**Изменить CSS селекторы:**
- Файл: `.env` (или n8n Environment Variables)
- Переменные: `DUMMY_CSS_SELECTOR_PRICE`, `DUMMY_CSS_SELECTOR_DESCRIPTION`

**Изменить AI промпт:**
- Файл: `workflow-b-competitor-price-scraper-rag-api.json`
- Нода: `RAG Agent`
- Параметры: `text`, `options.systemMessage`

**Изменить порог уведомлений:**
- Файл: `workflow-b-competitor-price-scraper-rag-api.json`
- Нода: `RAG Agent`
- Параметр: `options.systemMessage` (изменить "±5%")

**Добавить новые поля из Notion:**
- Файл: `workflow-a-competitor-price-scraper-main.json`
- Нода: `Code Extract Data & Handle Errors`
- Добавить извлечение: `item.json.properties['Новое Поле']`

## 💡 Советы

### Перед импортом:
- Убедитесь, что n8n обновлен до последней версии
- Установите @n8n/n8n-nodes-langchain если его нет
- Подготовьте все API ключи заранее

### После импорта:
- Сначала активируйте Workflow B (RAG API)
- Получите Webhook URL и сохраните его
- Протестируйте каждый воркфлоу отдельно
- Только потом активируйте автоматический запуск

### При ошибках:
- Проверьте Executions в n8n
- Убедитесь, что все credentials настроены
- Проверьте переменные окружения
- Обратитесь к разделу Troubleshooting в README
