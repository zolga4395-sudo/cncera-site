# CNCera v2.0 - Advanced Manufacturing Interface

Современная система для анализа 3D CAD файлов и генерации G-code с веб-интерфейсом.

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Запуск приложения

```bash
python run.py
```

### 3. Открыть в браузере

Перейдите по адресу: http://localhost:5000

## 📁 Структура проекта

```
cncera/
├── app.py              # Основное приложение Flask
├── index.html          # Веб-интерфейс
├── debug.js           # Скрипт отладки
```

## 🔧 API Endpoints

### Основные endpoints

- `POST /upload` - Загрузка и анализ CAD файлов
- `POST /generate_gcode` - Генерация G-code
- `GET /models/<filename>` - Загрузка файлов модели
- `GET /download_gcode` - Загрузка файлов G-code
- `GET /download_results` - Загрузка результатов анализа

### Служебные endpoints

- `GET /api/status` - Статус системы
- `GET /` - Главная страница

## 🛠️ Поддерживаемые форматы

### Входные файлы
- **STEP/STP** - CAD файлы (требует FreeCAD)
- **STL** - 3D модели

### Выходные файлы
- **G-code (.nc)** - Программы для ЧПУ
- **PNG** - Предварительный просмотр (если доступен matplotlib)

## 🎛️ Поддерживаемые контроллеры

- **Fanuc** - Промышленный стандарт
- **Siemens** - Немецкие системы
- **Heidenhain** - Высокоточные системы
- **GSK** - Китайские контроллеры
- **Mazak** - Японские станки

## 🔧 Операции обработки

- **Milling** - Фрезерование
- **Turning** - Токарная обработка
- **Drilling** - Сверление
- **Roughing** - Черновая обработка
- **Finishing** - Чистовая обработка

## 📋 Системные требования

### Обязательные
- Python 3.8+
- Flask
- numpy-stl

### Опциональные (для расширенной функциональности)
- **FreeCAD** - для конвертации STEP файлов
- **matplotlib** - для генерации превью
- **python-magic** - для проверки типов файлов

## 🔒 Безопасность

- Валидация типов файлов
- Ограничение размера файлов (50MB)
- Санитизация имен файлов
- Rate limiting
- Безопасная обработка временных файлов

Откройте http://localhost:5000/test.html

Проверьте файлы в директории `logs/`:
- `cncera.log` - основные логи
- `security.log` - логи безопасности

## 🚨 Устранение неполадок

### FreeCAD не найден
```bash
# Установите FreeCAD или укажите путь
export FREECADCMD_PATH=/path/to/FreeCADCmd
```

### Ошибки с matplotlib
```bash
pip install matplotlib
```

### Проблемы с CORS
Приложение настроено для работы с CORS. Если возникают проблемы, проверьте настройки браузера.

## 📝 Примеры использования

### Загрузка файла
```bash
curl -X POST -F "file=@model.stl" http://localhost:5000/upload
```

### Генерация G-code
```bash
curl -X POST -H "Content-Type: application/json" \
  -d '{"model_path":"/models/file.stl","controller":"fanuc","operation_type":"milling"}' \
  http://localhost:5000/generate_gcode
```
