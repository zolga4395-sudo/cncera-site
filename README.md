# 🚀 Агент мониторинга конкурентов для туристического бизнеса

Автоматический агент для мониторинга цен и описаний туров на сайтах конкурентов с отчетами в Telegram.

---

## 📌 Что делает агент?

1. ✅ Каждый день в 10:00 проверяет сайты конкурентов
2. 🔍 Извлекает цены и описания туров
3. 🤖 Анализирует изменения с помощью Claude AI
4. 📊 Сохраняет данные в Notion
5. 📱 Отправляет уведомления в Telegram при обнаружении изменений
6. 📈 Формирует итоговый отчет со статистикой

## ⚡ Быстрый старт

### Шаг 1: Импорт workflow в n8n
1. Откройте n8n
2. Нажмите **Import from File**
3. Выберите файл `tourism-monitoring-agent-fixed.json`
4. Нажмите **Import**

### Шаг 2: Настройка переменных окружения
Добавьте в n8n → Settings → Variables:
```
TELEGRAM_CHAT_ID=<ваш_chat_id>
NOTION_DATABASE_ID=<id_базы_данных>
```

### Шаг 3: Настройка Credentials
Создайте 3 Credentials в n8n:
- **Telegram API** (токен от @BotFather)
- **Notion API** (API key из Notion)
- **Anthropic API** (API key от Anthropic)

### Шаг 4: Создайте базу данных в Notion
Следуйте инструкции в `NOTION_DATABASE_EXAMPLE.md`

### Шаг 5: Настройте CSS-селекторы
Откройте **Node 4** в workflow и замените селекторы на реальные для ваших сайтов (см. `SETUP_INSTRUCTIONS.md`)

### Шаг 6: Запустите тест
Нажмите **Execute Workflow** в n8n

## 📊 Логика работы

```
CRON (10:00) 
    ↓
[Уведомление в Telegram] + [Загрузка списка из Notion]
    ↓
Загрузка HTML страниц
    ↓
Парсинг HTML
    ↓
IF: Парсинг успешен?
    ├─ ДА → AI анализ → Расчет цен → IF: Есть изменения?
    │                                    ├─ ДА → Отчет в Telegram
    │                                    └─ НЕТ → Обновление Notion
    └─ НЕТ → Уведомление об ошибке → Обновление Notion
                                           ↓
                                    Подсчет статистики
                                           ↓
                                    Итоговый отчет в Telegram
```

## 🔍 Отладка

### Проблема: "Цена не найдена"
**Решение:** Обновите CSS-селекторы в Node 4

### Проблема: "HTML не загружен"
**Решение:** Проверьте URL в Notion, возможно сайт блокирует запросы

### Проблема: "Данные не обновляются в Notion"
**Решение:** Проверьте названия полей и доступ API

Подробнее в `SETUP_INSTRUCTIONS.md` → раздел "Частые проблемы"
