# CNCera - Полный список возможностей

## 🤖 ИИ Интеграция

### ИИ Чат-консультант
- **Экспертные консультации** по CNC обработке в реальном времени
- **Контекстная помощь** с учетом загруженной детали
- **История разговоров** в рамках сессии
- **Специализированные знания** по:
  - Выбору инструментов и режимов резания
  - Стратегиям обработки
  - Материалам и СОЖ
  - Решению технологических проблем

### ИИ Анализ детали
- **Автоматический анализ геометрии** на основе размеров и сложности
- **Рекомендации по стратегии обработки** (черновая/чистовая)
- **Подбор инструментов** с учетом материала и геометрии
- **Оптимальные режимы резания** для конкретной детали
- **Оценка времени обработки** и сложности
- **Рекомендации по закреплению** заготовки

### ИИ Генерация параметров
- **Умный подбор параметров** на основе описания требований
- **Автоматическое заполнение формы** оптимальными значениями
- **Адаптивные рекомендации** с учетом размеров детали
- **Выбор контроллера и типа операции**

## 📊 Анализ и визуализация

### Поддержка форматов файлов
- **STEP/STP** - автоматическая конвертация через FreeCAD
- **STL** - прямая загрузка и анализ
- **Настройки конвертации** - LinearDeflection, AngularDeflection
- **Поддержка единиц** - мм, дюймы, метры

### 3D Визуализация
- **WebGL просмотрщик** на Three.js с полным 3D управлением
- **Оси координат** с цветовой индикацией (X-красный, Y-зеленый, Z-синий)
- **Интерактивное управление** - поворот, масштабирование, панорамирование
- **PNG превью** как резервный вариант для старых браузеров
- **Автоматический центр и масштаб** для оптимального просмотра

### Анализ геометрии
- **Размеры детали** - длина, ширина, высота
- **Сложность сетки** - количество вершин и граней
- **Bounding Box** с координатами центра
- **Координатные системы** G54 с автоматическим центрированием

## ⚙️ Генерация G-кода

### Поддерживаемые контроллеры
- **Fanuc** - стандартные G/M коды
- **Siemens** - адаптированный синтаксис
- **Heidenhain** - специальный формат (SPINDLE ON, L команды)
- **GSK** - китайские системы ЧПУ
- **Mazak** - специфичные команды (M99)

### Стратегии обработки
- **Фрезерная обработка** - универсальная стратегия
- **Черновая обработка** - с послойным съемом материала
- **Чистовая обработка** - точные проходы с малой подачей
- **Waterline** - контурная обработка по уровням
- **Комбинированные циклы** - черновая + чистовая

### CAM алгоритмы
- **Raster сканирование** - зигзагообразные проходы
- **Адаптивный stepdown** - послойная обработка
- **Marching Squares** - алгоритм для waterline
- **Оптимизация траектории** - минимизация холостых ходов
- **Collision detection** - проверка столкновений

### Параметры инструмента
- **Диаметр инструмента** - 0.1-50 мм
- **Скорость шпинделя** - 1000-24000 об/мин
- **Подача** - 10-5000 мм/мин
- **Скорость погружения** - настраиваемая
- **Степовер** - 5-95% от диаметра
- **Stepdown** - глубина за проход

### Координатные системы
- **G54 настройка** - различные точки начала координат
- **Bbox_min** - нижний левый угол
- **Bbox_center** - центр низа детали  
- **Bbox_top_center** - центр верха детали
- **Припуски** - ручная корректировка по осям X, Y, Z

## 🔧 Настройки и конфигурация

### Переменные окружения
```bash
OPENAI_API_KEY=your-key        # ИИ функции
FREECADCMD_PATH=/path/to/cmd   # STEP конвертация
FLASK_ENV=development          # Режим разработки
```

### Лимиты системы
- **Размер файлов** - до 100 МБ
- **Сложность сетки** - до 40,000 точек для CAM
- **Время выполнения** - таймаут FreeCAD 10 минут
- **История чата** - последние 20 сообщений

### Производительность
- **Адаптивное разрешение** - автоматическое упрощение сложных моделей
- **Кэширование** - сохранение результатов анализа
- **Оптимизация памяти** - освобождение ресурсов после обработки
- **Параллельная обработка** - использование всех ядер CPU
